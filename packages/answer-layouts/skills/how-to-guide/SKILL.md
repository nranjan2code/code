# A how-to guide

Explain what the person will accomplish and what they need before starting.
Use a Markdown checklist for prerequisites and ordered steps for actions.
Include details and durations when they help someone carry out the action.
Place warnings where the risk arises, and explain a useful shortcut in context.

Use only supplied facts, retrieved evidence or transparent calculations.
Do not repeat the steps in a separate summary. The runtime supplies layout;
no card call or plan deliverable is required for instructions.
