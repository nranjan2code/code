Where does my information go?

Vakyartha stores its work on the machine where you run it. Relevant parts of your request and files may be sent to the AI service you connect. Local models are an option. Connected tools have their own data handling.

Does it ask before every action?

No. Allowed actions can run within the access you have chosen. Other actions need approval or are blocked. Full access removes the operating-system sandbox and is an explicit choice.

Can it get things wrong?

Yes. Check important answers and proposed changes. A clear result is easier to review, but it is not a guarantee of correctness.

How do I know what is actually done?

Look at the result and the checks behind it. A draft, an accepted file change, and a sent message are different outcomes. Some checks can be verified directly; others rely on the AI’s judgment. Incomplete or unverified work should remain visible as such.

What does it remember about me?

Saved preferences and relevant earlier conversations can help with future work. You can review, edit and remove saved memories. They are scoped to the Agent and authorised audience; connecting another chat does not automatically share private history.

Can it learn how I like things done?

It can save useful preferences and propose reusable ways of working. You review and approve new reusable skills before they guide future work. A learned preference does not grant extra access.

What if work gets interrupted?

Stopped work preserves partial output, and temporary service failures have retry paths. Some work may still need your help to continue. You can inspect its status and what remains.

Technical details

Restricted file and command tools run through sandboxed workers. Permission rules are checked before dispatch. Changing permission mode cancels work using the old permissions. Session records preserve the inputs, actions and results for inspection.
