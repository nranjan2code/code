Where does my information go?

Vakyartha stores its work on the machine where you run it. Relevant parts of your request and files may be sent to the AI service you connect. Local models are an option. Connected tools have their own data handling.

Does it ask before every action?

No. Allowed actions can run within the access you have chosen. Other actions need approval or are blocked. Full access removes the operating-system sandbox and is an explicit choice.

Can it get things wrong?

Yes. Check important answers and proposed changes. A clear result is easier to review, but it is not a guarantee of correctness.

Technical details

Restricted file and command tools run through sandboxed workers. Permission rules are checked before dispatch. Changing permission mode cancels work using the old permissions. Session records preserve the inputs, actions and results for inspection.
