A core that runs without a desktop

Keep the work
within reach.

Vakyartha’s core runs as a service. It does not need an open desktop window or a display attached to its host. Your conversations, memory, and scheduled work live on the machine running your agent.

  • A browser workspaceUse the workspace client and administration console served by the same host.
  • Your chosen channelsConnect configured Telegram, Discord, or Slack bridges to your gateway, with access rules for each conversation.
  • Work that returnsCome back to the same agent, its ongoing commitments, and the results of the routines you set.

Your infrastructure. Your choice.

Give your agent
a cloud home.

Deploy the headless Linux server on your own virtual machine, or use the Docker setup with persistent storage. The hosting contract is independent of the cloud provider, with a worked AWS EC2 guide to get you started.

  • Run as a serviceManaged Linux services can start at boot and recover after a crash. Your host must stay powered and connected for routines to run.
  • Keep the historyPersist your workspace and agent data across container replacements and server updates. Back up the host’s data and credentials as part of your deployment.
  • Choose the modelsConfigure the model providers and keys you want your agent to use. Hosting and model usage have their own costs.

Reach it on your terms

Connect with care.

Use an SSH tunnel for private access, or configure your own HTTPS hostname. For a public browser address, enroll an owner passkey and keep recovery codes somewhere safe.

A private route in

An SSH tunnel keeps the server listening locally while you use its browser workspace from another machine. A private network is another option for hosts you control.

Your own web address

Put an HTTPS reverse proxy in front of the server and configure the exact public hostname. Browser sign-in, revocable sessions, and your agent’s permission rules continue to apply.

What you manage when you host it

You provide the server, storage, network access, updates, backups, and model credentials. The cloud provider operates the underlying infrastructure. Choose access and tools deliberately: a hosted agent can act on the workspace and integrations you allow.
