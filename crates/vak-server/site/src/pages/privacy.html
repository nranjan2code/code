Privacy and data.

What happens on this website and when you run Vakyartha.

Last updated 27 September 2026.

On this website

The public site does not ask you to create an account or submit a request. It uses no analytics script. A theme choice is saved in your browser's local storage, and the page requests its public build version. Wallpaper downloads do not require sign-in.

Vercel hosts the public site. Like other web hosts, it receives request information such as your IP address and the pages requested. See Vercel's privacy notice for its handling of that information.

When you run Vakyartha

Vakyartha stores conversations and work in the installation you run or the server you choose. The public website does not receive those conversations. The operator of a server you use controls that server's storage and access.

If you connect an AI provider, a tool, or a chat service, relevant requests, files, or messages may go to that service so it can do the work you asked for. Its own terms and privacy practices apply. You can choose a local model and control which tools and folders Vakyartha may use. See Your control for more on those choices.

Questions and reports

For a general question, use the public issue tracker. Do not post private data or credentials there. Report a security issue through a private security advisory.
