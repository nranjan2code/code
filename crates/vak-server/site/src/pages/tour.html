How to read the Vak 3D Citadel

Each structure in the virtual world corresponds to a real Rust crate and architectural boundary in this repository. Unlike traditional black-box agent loops where tools execute invisibly, Vak isolates every effect behind observable barriers.

Sectors 1–3 · Ingress & Memory The Surface Bastion, Security Citadel, and Append-Only Archive enforce that no stranger gains access without an allowlist entry, no chat escalates beyond its bot identity, and every model-visible byte is permanently logged in append-only JSONL before any model call is made.
Sectors 4–6 · Intent & Planning The Intent Observatory, Route Spire, and Context Tokamak resolve what the user actually wants, narrow the capability slice, assemble a fresh route ladder on every single turn, enforce FinOps budget admission, and proactively compact overflowing tokens.
Sectors 7–8 · Inference & Containment The Neural Core and Quarantined Subprocess Foundry manage streaming token deltas and snapshots. If the model invokes tools, the calls cross an IPC broker into disposable __tool_worker process groups with sanitized environments.
Sectors 9–10 · Precedence & Delivery The Precedence Tribunal and Receipt Spaceport enforce the four-stage policy engine (Deny wins outright; Ask pauses execution). When finished, every dispatch writes a settled WorkReceipt with token usage, cost, and latency before output is delivered.
