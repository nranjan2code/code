# Dimensional visual pack

Status: **selectable optional visual pack**. In Vakyartha, open **Settings →
Appearance → Visual pack → Dimensional 3D**. The choice is saved locally in
`vak.uiPreferences`, applies immediately in the client, and is read by the
public site and admin UI on their next page load in the same browser origin.

The pack includes:

- eight individual transparent character portraits at 64, 128, 256, and
  512 px, and face-focused transparent glyphs at 32, 64, and 128 px;
- a transparent 3D Songbird illustration;
- light and dark transparent lockups for the app and public site;
- a 3D app icon at 32, 64, 192, 512, and 1024 px.

Runtime exports live under
`crates/vak-client-ui/public/assets/brand/dimensional/`. The five approved
new individual sources are in [`characters/`](characters/). Mira, Moss, and
Beni use their existing transparent 3D masters in `docs/brand/characters/`:
new generation studies for those three left broad coloured halos, so they
remain exploration files and are not shipped as cutouts. Their selection in
this pack is deliberate, not a missing file.

## Motion and size behavior

The new 3D portrait or glyph is the **idle** image. During listening,
thinking, work, waiting, success, concern, and acknowledgement, `AgentMark`
uses the established expression atlas for that character. This preserves
state-driven motion, pointer acknowledgement, sound cues, visibility pausing,
and reduced-motion behavior. These assets are still 2D renders of 3D-looking
artwork; no rigged 3D model or skeletal animation is included. The idle
image changes at runtime without changing the Agent's persisted character id
or session identity.

The generated 32 px face glyphs are an optional visual treatment. The
two-colour flat glyphs in visual-refresh item V4.6 are a separate pending
small-size system. A 32 px raster portrait must be inspected on each theme
before it is made the default for everyone.

## Rebuild

```sh
npm ci --prefix scripts/brand
npm --prefix scripts/brand run dimensional
npm --prefix scripts/brand run dimensional:check
```

`scripts/brand/export-dimensional-pack.mjs` declares every source and head
crop, checks alpha and minimum dimensions, then writes all size tiers,
lockups, and icons. It uses `sharp` 0.35.4 pinned by `scripts/brand`.
`--check` compares every generated byte. For a newly generated individual
character, save its transparent source here, add the source path and explicit
head crop to the script, and run both commands. Keep any rejected versions
under a dated exploration with the reason they were rejected.

The 3D Songbird is derived from the flat symbol but is not geometry-perfect.
The SVG master in `docs/brand/mark/` remains authoritative for print, tiny
icons, and the default platform installation icons. This pack changes web
content, the browser favicon, and the running desktop window icon at runtime
where the operating system supports it. macOS Dock, Windows installer, and
installed mobile home-screen icons are selected at packaging/install time by
the platform and cannot be changed by this preference.

## Provenance

[`prompts.md`](prompts.md) records the reference artwork, generated outputs,
and exact prompt text for the five new approved individual cutouts. The
Songbird and wallpaper prompts are in the parent library's
[`prompts.md`](../prompts.md). The existing Mira, Moss, and Beni masters
predate this pack and have no generation prompt recorded in the repository;
their saved transparent PNGs are the reproducible inputs for this build.
