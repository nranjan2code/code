# Headless & Cloud scenes

Two generated Songbird illustrations for the public homepage and Headless & Cloud page.
Canonical character reference: `docs/brand/mascot/vak-songbird-pose-03.png`.
Final 1200 × 800 transparent PNGs: `crates/vak-server/site/src/assets/cloud/`.

- `server.png`: Songbird beside a navy server tower, floating white cloud, laptop and phone; private hosting and remote access.
- `continuity.png`: Songbird organizes tasks beside a clock and running server, with connected laptop and phone; scheduled work and returning from another device.

Direction: preserve canonical blue feathers, cream face, saffron throat, swept crest and brown eyes. Premium dimensional studio illustration, transparent background, restrained indigo/cream/saffron palette, tactile equipment and soft contact shadows. No text, platform logos or background scenery.
