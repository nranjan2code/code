# Mail and calendar scenes

Three transparent, dimensional website illustrations of the Vakyartha
Songbird. They extend the existing public-site story style for selected mail,
calendar planning, and review. The site's 1200 × 800 PNGs are in
`crates/vak-server/site/src/assets/email/`; the generated 1536 × 1024 originals
remain in the Codex generated-images folder for this task.

Each image was generated with the public Songbird pose and the continuity
scene as identity and style references. Prompts are preserved in the adjacent
`.prompt.txt` files.
