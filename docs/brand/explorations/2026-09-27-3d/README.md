# Vakyartha dimensional character study

Status: **concept exploration, not production brand artwork**. The approved flat
Songbird and exported platform assets remain the identity source.

Generated with the built-in image generation tool using the existing Songbird
and character portraits as visual references. These images explore how the mark
and eight agent characters might appear as tangible objects or lifelike beings.

| Image | Prompt direction |
| --- | --- |
| [Songbird sculpture](songbird-sculpture.png) | Preserve the mark's swept crest, eye, open V wing and saffron throat as a satin indigo ceramic sculpture with an enamel throat, photographed on warm paper. |
| [Lifelike Vak](vak-lifelike.png) | Keep Vak's existing proportions, crest, cream face and saffron throat while adding plausible feather detail in a sunlit desk portrait. |
| [Vak, Beni, Mira and Tavi](agents-vak-beni-mira-tavi.png) | Place the four referenced characters in a shared sunlit studio with tactile fur and feathers and their established expressions. |
| [Lumi, Moss, Nori and Pip](agents-lumi-moss-nori-pip.png) | Place the four referenced characters in the same visual world, using vapor, moss, fur and feathers suited to each identity. |

These raster studies are mood and material references. The sculptural rendering
slightly rounds the mark's geometry, so it should not be used as a replacement
logo or redrawn into a platform icon without a geometry review.
