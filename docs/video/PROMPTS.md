# VAK architecture video prompts

## Master creative prompt

Create a 90-second, 16:9 technical explainer for VAK, a personal AI operating system. Use flat 2D motion graphics, clean editorial typography, restrained navy/teal/coral/amber/lavender/sage accents, and precise diagram animation. Explain one request from channel ingress through trust resolution, `vak-core`, the direct agent loop, permission and brokered tools, Managed Flow, the append-only ledger, semantic delivery, and Operations Center. Keep the tone calm, intelligent, and trustworthy. No 3D, sci-fi, neon, hacker clichés, or generic cloud imagery. Animate only meaningful transitions: cards assemble, arrows trace, policy gates close or open, ledger entries append, and output projections fan out.

## Scene prompts

- Opening: “One request. One governed runtime.” Show multiple channel icons converging into a single VAK mark.
- Trust: Show `surface : chat [: bot_id]`, allowlist states, bot → chat → workspace policy, and a clear denied/pending branch.
- Core: Show `vak-core` as a coordinator, not a model and not a UI; orbit config, session, agent, permission, tools, provider, delivery.
- Agent loop: Show project → stream → append → stop gate → authorize → broker → sandbox → ToolResult → continue.
- Managed Flow: Contrast direct work with contract → work items → evidence → verification.
- Ledger: Animate append-only JSONL lines growing into a parent-pointer tree; project it into context, search, transcripts, and ops.
- Delivery: Transform one semantic result into desktop, CLI, Telegram, SSE, and retry outbox outputs.
- Operations: Show observation, evidence projection, operator action, post-action probe, and receipt.
- Closing: “Many entry points. One governed runtime. Observable end to end.”

## Voice direction

Use a warm, confident technical narrator at a moderate pace. Pause briefly after each architecture layer. Pronounce `vak-core` as “vak core”, `vak-agent` as “vak agent”, and JSONL as “jay-son-el”. Keep music below narration and use subtle clicks or soft pulses only at major transitions.
