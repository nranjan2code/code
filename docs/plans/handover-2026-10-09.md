## How to verify

```
cargo fmt --all --check && cargo clippy --workspace --all-targets -- -D warnings && cargo test --workspace --no-fail-fast
scripts/check-version.sh && python3 scripts/check_doc_paths.py
```

- The suite takes about 20 minutes. Run it in the background writing to a
  new log, end the log with a `done` line, and wait with
  `until grep -q "^done" <log>; do sleep 15; done`. The waiter usually
  needs two 10-minute calls.
- Run `cargo clippy --all-targets` on the crates you changed before the
  full run; it catches most failures in a minute.
- Never edit Rust sources while a suite or a Docker build is running.
- After a frontend edit, rebuild its bundle or the server will not
  compile: `npm run build` in `crates/vak-admin-ui` or
  `crates/vak-client-ui`.

## Traps that cost time last session

- **Shell:** the shell is zsh, which does not split `$VAR` into words.
  Put multi-command helpers in an `sh` script or a function.
- **`rm` inside `sh -c "…"` strings is blocked** by the harness. Remove
  files with a plain `rm` of a fixed path, or leave them.
- **`timeout` is not installed** on this Mac.
- **A pull, a restore and a key-file import fence the process** that ran
  them. A test that needs to write afterwards drives a second data home
  with the `vak` binary (`VAK_HOME`, and `HOME` set to a scratch folder
  so no OS keychain is reached). See `crates/vak/tests/sync_*.rs`.
- **Anything that fences or empties the home needs a test binary of its
  own**: restore, erase everything, the sync routes.
- **`AGENTS.md` has one very long paragraph.** Pipe any grep of it
  through `cut -c1-200`.
- **A server route that erases must drop the live session handles it made
  stale**, and its test must read the conversation back through the
  server with the handle attached. This was missed for five steps.
- **Python edit scripts abort on a failed `assert` after `cargo fmt`
  rewraps text**, leaving the edit half applied. Check which files were
  written before going on.
- **`/workspaces/open` only accepts folders under `[server]
  workspace_roots`.** To make a second project on a throwaway server use
  `vak exec -C <dir> --trust "<prompt>"` against the same `VAK_HOME`.
- **`/search` from one workspace does not find another Agent's
  conversations.** Check an Agent's erasure by its transcript route.
